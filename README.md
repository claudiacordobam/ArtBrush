# 🎨 ArtBrush

[![Processing](https://img.shields.io/badge/Processing-4.3-blue)](https://processing.org/download/)

A **mini Paint app** built in Processing with **brush size control**, **color palette**, **undo/redo**, and **save functionality**.  
Created just for fun and to learn more about Processing 😄.

---

## 🌈 Features

- Draw freely with a **brush** of adjustable size (`+` / `-`).  
- Choose colors from a **palette**.  
- **Undo** (`Z`) and **Redo** (`Y`) strokes.  
- **Reset** canvas with a button.  
- **Save** artwork as PNG (`S`).  
- Custom **cursor preview** showing the current brush size and color.

---

## 🎮 Controls

| Action | Key / Mouse |
|--------|-------------|
| Draw | Click + Drag |
| Change Brush Size | `+` / `-` |
| Select Color | Click on palette |
| Reset Canvas | Click **Reset** button |
| Save Drawing | `S` |
| Undo | `Z` |
| Redo | `Y` |
